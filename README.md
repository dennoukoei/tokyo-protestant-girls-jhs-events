# 東京プロテスタント女子中学校イベントスケジュール

[![Netlify Status](https://api.netlify.com/api/v1/badges/YOUR_SITE_ID/deploy-status)](https://app.netlify.com/sites/classy-melba-6beb8e/deploys)

> 東京都内のプロテスタント系女子中学校8校の説明会・イベントスケジュールを統合表示するレスポンシブWebアプリケーション

## 🎯 概要

このプロジェクトは、東京都内の主要なプロテスタント系女子中学校8校の入学説明会・学校見学会・文化祭などのイベント情報を一つのサイトで閲覧できるWebアプリケーションです。

**主な特徴:**
- 📱 完全レスポンシブ対応（デスクトップ・タブレット・スマートフォン）
- 🔍 高度なフィルタリング・ソート機能
- 📅 日付ベースの自動表示管理
- ⚡ バニラJavaScript（フレームワーク不使用）
- 🎨 モダンなUI/UX デザイン

## ✨ 主な機能

### 📊 表示・ソート機能
- **日付順ソート**: 昇順（古い→新しい）がデフォルト
- **学校名ソート**: あいうえお順・逆順
- **イベント種別ソート**: 種別名でアルファベット順

### 🔎 フィルタリング機能
- **学校別フィルター**: 特定の学校のみ表示
- **イベント種別フィルター**: 説明会、見学会、オープンスクール、体験、文化祭/体育祭など
- **月別フィルター**: 2025年9月〜2026年3月の各月
- **過去イベント非表示**: 現在日付より前のイベントを自動非表示

### 📱 レスポンシブデザイン
- **デスクトップ**: テーブル形式での一覧表示
- **モバイル**: カード形式での見やすい表示
- **タッチ対応**: スマートフォンでのスムーズな操作

### 🎨 UI/UX機能
- **統計表示**: 学校別イベント数の可視化
- **リアルタイム検索**: フィルター条件の即座反映
- **結果件数表示**: 現在表示中のイベント数
- **外部リンク**: 各イベントの詳細ページへ直接アクセス

## 📋 データソース

**Study1.jp** (https://www.study1.jp/) から以下の情報を収集:
- イベント日時
- 学校名
- イベント種別（説明会、見学会、オープンスクール等）
- 詳細ページリンク

### 収集対象期間
2025年9月〜2026年3月（7ヶ月間）

### データ更新
Python スクリプトによる手動更新
```bash
python study_month_calendar_scraper_landscape_full_colors_fixdates.py --batch-to-2026-03
```

## 🚀 セットアップ・開発

### 必要環境
- Python 3.9以上
- モダンWebブラウザ（Chrome, Firefox, Safari, Edge）

### データ収集
```bash
# 必要パッケージのインストール
pip install requests beautifulsoup4

# データ収集の実行
python study_month_calendar_scraper_landscape_full_colors_fixdates.py --batch-to-2026-03
```

### ローカル開発
```bash
# リポジトリのクローン
git clone https://github.com/dennoukoei/tokyo-protestant-girls-jhs-events.git
cd tokyo-protestant-girls-jhs-events

# ローカルサーバーの起動（Python使用例）
python -m http.server 8000

# ブラウザでアクセス
open http://localhost:8000
```

### デプロイ
Netlifyへの自動デプロイが設定済み:
1. `main`ブランチへのpush
2. Netlifyが自動でビルド・デプロイ
3. 数分でサイトが更新

## 🎯 使用方法

### 基本操作
1. **イベント一覧の閲覧**: サイトにアクセスすると全イベントが日付順で表示
2. **ソート**: テーブルヘッダーをクリックして並び替え
3. **フィルタリング**: 上部のコントロールパネルで絞り込み
4. **詳細確認**: 「詳細」リンクから各学校の公式ページへ

### モバイル利用
- スマートフォンでは自動的にカード形式で表示
- スワイプ・タッチ操作に完全対応
- フォント読みやすさを16px以上に設定（iOS ズーム防止）
